# agent-record

`agent-record` holds every past coding-agent session on this machine: what was said, decided and done.

- A handoff, plan or memory is a snapshot. Before acting on one, search the record for what was decided after it (the `search-sessions` skill, or `agent-record query search "<words>"` then `query thread`). A later decision wins.
- When the owner says "we agreed" or "check the record", search it before answering from memory.
